En el siguiente laboratorio, se evalúa el uso de SQL como mecanismo de registro y plataforma para consultas sobre una base de datos. En este caso se trabaja bajo una base de datos de la compañía Andes Bike, la cual dispone de 4 sedes, 8 trabajadores y 8 modelos de bicicletas diferentes. Se poseen 4 tablas consolidadas con la información a ingresar en la base de datos, Tiendas, Trabajadores, Bicicletas y Ventas. Estas 4 tablas son generadas dentro de SQL para luego ingresar todos los datos y registros dentro de cada una, a partir de estos datos se realizaron 10 encuestas que estudian relaciones y comportamientos según tiendas, trabajadores, modelos etc.
